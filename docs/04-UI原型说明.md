## 4. 各页面实现要点

### 4.1 首页看板 `dashboard`
- 顶部 `NoticeBar`：对账结果（matched ✓ / diff ⚠"中介差房"）；数据源 §5.5。
- 数字卡行（`.row.cards`）：收入 / 成本 / 利润 / 间夜 / ADR / 入住率 + **环比**（`.delta.up/down`）。
- 图：月度收入/成本/利润折线（§5.2）；成本结构环形图（§5.3，固定/变动/一次性 = 3 段 + TOP 项表）；线上/线下占比 + 渠道 TOP（§5.4）。
- 空态：当月无数据时展示引导"去导入 / 上手录"。

### 4.2 成本分析 `cost`
- 主表格（§6.1）：名称 / 金额 / 类型标签 / 备注 / 来源 / 操作；顶部三类小计卡（§6.5）。
- 顶部操作：`＋ 手录`、`导入`（复用 ImportDialog）、月份切换。
- 趋势：按月三条线 固定/变动/一次性（§6.6）。
- 类型标签配色固定：fixed=主题色、variable/once 各一色（见 2.1 色板语义位）。

### 4.3 销售渠道 `channels`
- 渠道×月表（§7.4）：渠道 / 类型 / 间夜 / 到手收入 / 挂牌(线上) / 佣金 / 到手均价 / 占比。
- 图：间夜柱状（渠道分类 × 月）；线上 vs 线下占比环形。
- **无渠道管理页**——渠道建档走导入；佣金调整在设置页（§7.3 入口）。

### 4.4 利润分析 `profit`
- 逐月利润表（§8.1）：月份 / 收入 / 成本 / 净利 / 间夜 / ADR / 单间夜利 + 同比（`yoy` 小标签）。
- 图：净利趋势 + 收入≈成本堆叠（单轴，勿用双 Y 轴）。

### 4.5 房态 · 入住率 `occupancy`
> 口径：**按具体房间登记**（哪天哪几间住了），杜绝"笼统几间"。可售房间数由 `room` 字典 `enabled=1` 推导，入住率/对账都基于具体房号。

- **房间 × 日期 入住矩阵**（主体，§9.4 + `RoomMatrix.vue`）：行=房间（101~/201~ 分组标注房型）、列=当月每日；已入住格高亮（选中态色块），空房格淡点；表头周末/节假日日期着色；逐日汇总行 + 逐房汇总列（当月入住天）。
  - 交互：点某格 = 切换该房该日入住（写 `daily_occupied_room`）；列头旁"当日"快捷操作（整排勾选/清空）；顶部"批量补录"按钮（§9.5 逐日多选房号）。
  - 原型已实现 22 日 × 10 房矩阵（占用 198 格，与看板/对账一致）。
- 每日聚合表（§9.1）：日期 / 入住房间数 / 可用间数 / 入住率 / 周末节假日标记 / 来源，供核对行列汇总。
- 当日房间列表（§9.3）：某日入住的具体房号（`day-rooms`），可增删房号。
- 对账卡片（§9.6）：房态间夜 vs 流水间夜、diff；diff≠0 时列出"上报少/实测多"的渠道，引导排查中介差房。

### 4.6 定价 · 预测 `pricing`
- 三合一面板：**档位价目**表（§10.1-10.4，CRUD 与设置页共享）+ **目标倒推计算器**（§10.8，滑块实时算，可保存 §10.9）+ **临近日建议价**（§10.5-10.7，逐日表 + 手动改价锁定）。
- 预测 + LLM 解读（§10.11-10.13）：预测值 + 置信区间区间条 + `AiBox` 解读；旁车不可用显示降级通知。
- 建议价表每行可"改价"按钮 → `PUT` 后 `source=manual`，与引擎价区分颜色。

### 4.7 回本测算 `breakeven`
- 方案参数卡（§11.2）：投资 / 自有 / 贷款 / 利率 / 年限 / 月净流入；滑块联动（复用 SliderCalc）。
- 结果：月供、回本月份高亮（§11.5）；逐月现金流表（进度条感：前段红后段绿）+ 累计余额曲线。
- 敏感度 tab（§11.6）：对 月净流入/月供/投资 拉敏感度表或 Sparkline。

### 4.8 设置 · 基础数据 `settings`（新增视图）
> 设计基调：**主数据自动化优先**——费用项、渠道、**房号**在"月度导入确认"时自动识别建档，本页**不做**费用项/渠道维护表，只维护导入无法获知的信息：房间的房型/楼层/停用、渠道佣金率、档位价目、酒店配置。

| 卡片 | 内容 | API |
|---|---|---|
| 提示条 | "费用项、渠道、房号在月度导入时自动识别建档；本页只维护导入无法获知的信息" | — |
| 酒店配置 | 酒店名 / 城市(可空) / 默认线上佣金率 / 每月营业天数常数 / 修改密码（**无"可售房间数"手填项**） | §13.1/13.2 |
| 房间管理 | 房号 / 房型 / 楼层 / 状态(启用·停用) / 排序 / 操作；**可售房间数 = 启用间数**自动推导（示例 10），供入住率/目标倒推/回本共用；停用 = 维修/长包不参与可售；导入出现未建档房号自动建档 | §13.6-13.9 |
| 档位价目 | 档位表 CRUD（与 pricing 页共享同一表格组件） | §10.1-10.4 |
| 渠道佣金率 | 只列"改佣金 / 停用 / 手动新增"，不维护建档 | §7.1-7.3 |
| 模板下载 | 「月度记账模板.xlsx」三 Sheet 说明 + 下载按钮（房态 Sheet 为「日期/房号」列） | §12.1 |

输入组件样式沿用 `.btn`（原型里月份选择器同款，文本输入加 `font-family:inherit`、左对齐即可）；保存按钮执行后 Toast 成功。

## 5. 导入对话框（全局复用，核心交互流程）

```
[上传] 选文件 + 选月份 → POST /api/imports（12.2）
   → loading "解析中…"（旁车不可用则 NoticeBar 降级"可手动归类"）
[预览] GET /imports/{id}/preview（12.4）→ 三 Sheet 预览（成本/房态/销售）
       —— 房态 Sheet 按「日期 / 房号」行展示，未建档房号预标注"将自动建档"
[映射] GET /imports/{id}/mapping（12.5）→ 归类建议表格：
       原始名 | 建议费用项 | 置信度 | 类型 | [待确认] 下拉改
       高置信度行绿色✓ 自动勾选；低置信度黄标需人工确认。
[确认] POST /imports/{id}/confirm（12.6）→ 结果摘要（新建费用项/渠道/**房号**、对账状态）
```

- 映射表格行内：原始名 + 候选下拉（搜索字典）+ "作为新费用项"选项。
- 渠道行若未识别 → 提示归属（选已有 / 新建 + 类型 + 默认佣金率）。
- 房态 Sheet 的房号未建档 → confirm 自动创建（`createdRooms` 回显），房型/楼层到设置页补。
- 冲突（同月重复导入）→ 40900 弹窗，提示先删旧批次。

## 6. 图表规范（dataviz 落地）

1. **单轴原则**：所有组合指标（如收入 vs 成本）不同量纲 → 拆两图或同轴堆叠，**禁用双 Y 轴**。
2. **色彩按语义**：类别色固定顺序（色板 `c[0..7]`），**永远不循环给第 9 类**——超出折叠进"其它"。数量/梯度用单色阶。
3. **标记规格**：折线 2px、数据点 ≥8px、柱体 ≤18px、堆叠/相邻段间留 2px 表面缝隙；关键值直接标注（绝不每点标数）。
4. **图例**：≥2 序列必有图例（顶部，悬停联动 `legend`）；单序列不需要图例（由标题自述）。
5. **表格兜底**：每个图表页都提供同数据表格（或导出），不依赖颜色传达唯一信息。
6. **主题**：暗色单独走 `PAL.dark` 色板（非简单反色）；两套色板均须过 dataviz validator。
7. **交互**：折线/面积默认 crosshair+tooltip；柱/点默认 item tooltip；命中区 ≥ 标记本体；hover 高亮 focus 系列。

### 6.1 色板语义位（前端共用约定）

| 位 | 用途 |
|---|---|
| `c[0]` 主题蓝 | 主指标/常规线（收入、固定成本） |
| `c[1]` 绿 | 正向/达成/状态 ok |
| `c[2] c[3] c[4]` | 类别序列（渠道、费用类型） |
| `c[7]` 红 | 警告戳/差异/负向（对账 diff、亏损） |
| 状态双色 | tag.ok(绿) / tag.warn / tag.fixed-var-once(蓝/暖/玫) |

（原型中 `tag.fixed/.var/.once/.warn/.ok` 已按此实施。）
