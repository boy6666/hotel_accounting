## FW-10 定价 · 预测 `pricing`（三合一）

- **顶部 4 stat 卡**（`03 §8.1` + `§10.5` 汇总）：
  - 本月实际均价（`/api/profit/monthly` 当月 adr）；
  - 未来 14 天建议均价（`/api/pricing/suggestions` 区间均值，待生成可显示「未生成」+ 生成按钮）；
  - 下月预测入住率（`/api/prediction/results?target=下月`，occupancy_rate 指标；无则"—"）；
  - 预警/亮点（临近日有手动锁定 or 节假日命中 → 提示文案）。
- **建议价卡**：
  - 区间选择（默认今天→+14 天）→「生成建议价」按钮 `POST /api/pricing/suggestions/generate` → 折线图展示逐日建议价（`GET /api/pricing/suggestions?from&to`），标注周末/节假日/预测入住率，`source=llm/engine/manual` 区分样式（手改标「锁定」）；
  - 行内可手改价 → `PUT /api/pricing/suggestions/{bizDate}`（source=manual，重新拉列表）；
  - 档位价目表（`GET /api/pricing/tiers`，只读展示 + 链接设置页；行内有权重序号）。
- **目标倒推卡**（`SliderCalc.vue`，`GET /api/pricing/calc/target`）：
  - 滑块：目标月收入 / 目标入住率 / 可售房间数（默认取 `room` enabled=1 计数，可 what-if 手改）→ 实时显示「需要达到的均价」；
  - 「保存方案」→ `POST /api/pricing/calc/scenarios`（name 可空）；「最近方案」下拉 ← `GET /api/pricing/calc/scenarios`。
- **预测卡**：
  - 月份（默认下月）+ 指标下拉（revenue / nights / occupancy_rate / adr / price）→「生成预测」`POST /api/prediction/generate`；
  - 结果：预测值大字 + 置信区间（confidenceLow~High）+ engine 标签（statistical/hybrid/llm）+ 逐月趋势小图；
  - `llmInterpretation` 有值 → 渲染进 `AiBox.vue`（✦ 捌宿·智能经营分析）；为空/旁车不可用 → AiBox 灰态「智能服务暂不可用，以上为纯统计结果」；
  - 「预测历史」`GET /api/prediction/results?target=` 列表可点击回看。
- 仪表联动：建议价图命中的档位与档位表高亮；预测与目标倒推结果可互相引用（文案：「按该预测，需均价…」）。

**验收**（2026-08/09 seed 锚点）：
- `GET /api/pricing/tiers` → 平日价 260 / 周末价 360 / 节假日价 520 三行；
- 目标倒推 `?targetRevenue=80000&targetOccupancy=85&roomCount=10` → ¥309.6（格式化 ¥310 可行）；
- 生成建议价 2026-08-23→2026-09-05 → 14 行折线，9/30–10/07 段命中节假日价 520、周末命中周末价、其余平日价，occupancy_forecast 有值（daily 预测可用时）；
- 预测 2026-09 revenue → predictedValue>0 且 confidenceLow<value<confidenceHigh、engine 字段、断旁车时给降级提示不白屏；
- 手改某日价 → 该行标「锁定」并刷新后保留。

## FW-11 回本测算 `breakeven`（参数卡 + 现金流 + 敏感度）

- **顶部 stat 卡**：总投入 / 贷款额 / 月供（active 方案的 `monthlyPayment`）/ 预计回本（`breakEvenMonth` 转「≈ X.X 年」）。
- **参数卡**（`03 §11.1–11.4`）：
  - 方案下拉列表（`GET /api/breakeven/scenarios`，渲染 name + 投资额）+「＋ 新建」/「编辑」/「删除」；
  - 表单字段：name / investment / ownCapital / loanAmount / loanRate / loanYears / monthlyNetInflow；
  - 保存 `POST /api/breakeven/scenarios`；编辑 `PUT /api/breakeven/scenarios/{id}`（**改参即触发后端现金流重算**）；删除 `DELETE`（确认框，提示级联删现金流）。
- **现金流卡**（`GET /api/breakeven/scenarios/{id}/cashflow`）：
  - 累计现金流折线（running_balance 逐月，回本点用 markLine 标注）+ 贷款还贷结构（本月供/累计已还/剩余本金，可按还款结构简单近似或只展示月供构成）；
  - 逐月表（DataTable）：月序 / 流入 / 流出(月供) / 净额 / 累计余额 / 备注；**首次累计 ≥0 的行高亮「回本点」**；
  - 空态：无方案 → 引导新建。
- **敏感度卡**（`GET /api/breakeven/scenarios/{id}/sensitivity`）：
  - 按接口返回渲染 3 行 × 5 列网格（维度：月净流入 / 月供 / 投资额；列：−20%/−10%/基准/+10%/+20%），每格 = 回本月数（未回本标「∞/—」）；基准格高亮。
- 数字一律千分位；金额字符串化（后端 BigDecimal 序列化为字符串）。

**验收**：
- 用 seed 方案参数（投资 2,000,000 / 自有 800,000 / 贷款 1,200,000 / 3.8% / 10 年 / 月净流入 20,000）新建 → 月供 **¥12,035.68**、回本月 **151**（=⌈1,200,000 ÷ 7,964.32⌉，docs §11.5 示例 58 为旧占位，以 07 工单为准）；
- 现金流 151 行、第 151 行累计 ≥0 高亮；改月净流入 20,000→30,000 → PUT 后刷新回本月变（67）；删除方案后现金流消失。
